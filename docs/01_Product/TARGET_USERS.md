# Target Users

**Product:** SKYNEX

---

# Overview

SKYNEX is designed for organizations that operate cloud environments and require a centralized platform for investigating and managing cloud security risks.

The platform focuses on enterprise users responsible for cloud security, DevSecOps, compliance, and operational resilience.

---

# Primary Users

## Cloud Security Engineer

### Responsibilities

- Investigate cloud security findings
- Prioritize security risks
- Validate remediation
- Improve cloud security posture

### Goals

- Reduce investigation time
- Improve visibility
- Track risks efficiently

---

## Security Analyst

### Responsibilities

- Analyze security alerts
- Investigate incidents
- Correlate findings
- Produce investigation reports

### Goals

- Understand incidents quickly
- Reduce false positives
- Improve response quality

---

## DevSecOps Engineer

### Responsibilities

- Secure CI/CD pipelines
- Review infrastructure changes
- Monitor cloud security posture
- Improve deployment security

### Goals

- Shift security left
- Detect risks early
- Automate security processes

---

## Platform Engineer

### Responsibilities

- Manage cloud infrastructure
- Support engineering teams
- Maintain platform reliability

### Goals

- Improve operational stability
- Maintain secure infrastructure
- Support scalable deployments

---

# User Needs

Every user expects:

- Fast investigations
- Clear dashboards
- Actionable recommendations
- Reliable reporting
- Secure access
- High platform availability

---

# User Experience Principles

SKYNEX should provide:

- Simple navigation
- Consistent interface
- Fast performance
- Clear visual hierarchy
- Enterprise-grade usability
- Accessibility support

---

# Engineering Principle

Every feature implemented in SKYNEX must improve the experience of at least one target user.

If a feature provides no measurable value to a defined user group, it should be reconsidered before implementation.
